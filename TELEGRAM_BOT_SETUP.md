# Настройка Telegram-бота для получения заявок с сайта

Заявки с формы **«ТЕСТ-ДРАЙВ ВЕРЫ»** отправляются на сервер, а сервер пересылает их в Telegram через официальный Bot API. Токен бота хранится только на сервере (в переменных окружения), поэтому пользователи сайта не могут его перехватить.

---

## Шаг 1. Создание бота в @BotFather (1 минута)

1. Откройте в Telegram диалог с [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите название бота (например: `Optima Leads Bot`).
4. Введите юзернейм бота, оканчивающийся на `bot` (например: `altai_optima_leads_bot`).
5. @BotFather пришлет вам **HTTP API TOKEN** (выглядит как `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`).
   - Сохраните этот токен — это значение `TELEGRAM_BOT_TOKEN`.

---

## Шаг 2. Создание чата для заявок (1 минута)

1. Создайте в Telegram группу (например, **«Заявки Optima»**) и добавьте туда основателей.
2. Добавьте созданного бота в эту группу и назначьте его администратором (чтобы он мог отправлять сообщения).
3. Напишите любое сообщение в группу (например, `тест`).
4. Узнайте **Chat ID** группы:
   - Откройте в браузере:  
     `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
   - Найдите в ответе объект `"chat":{"id": -100xxxxxxxxxx, ...}`.
   - Число (начинающееся обычно с минуса, например `-1001987654321`) — это ваш `TELEGRAM_CHAT_ID`.
   
*(Если хотите получать заявки в личку, а не в группу — просто напишите боту `/start`, перейдите по той же ссылке `getUpdates` и скопируйте свой персональный `id` без минуса).*

---

## Шаг 3. Подключение токенов на сервере

### Вариант А: Если сайт развернут на Vercel / Node.js
В панели управления проектом перейдите в **Settings → Environment Variables** и добавьте две переменные:
- `TELEGRAM_BOT_TOKEN` = `1234567890:ABC...`
- `TELEGRAM_CHAT_ID` = `-100xxxxxxxxxx`

Обработчик находится в файле [`api/lead.js`](file:///Users/alinazhalilova/Documents/altai-optima/api/lead.js) и будет автоматически вызываться по адресу `/api/lead`.

### Вариант Б: Если сайт на классическом PHP-хостинге (Beget, TimeWeb, Reg.ru и др.)
В корне проекта создайте файл `.env` (рядом с `.env.example`) со следующим содержимым:
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
TELEGRAM_CHAT_ID=-100xxxxxxxxxx
```
Файл [`api/lead.php`](file:///Users/alinazhalilova/Documents/altai-optima/api/lead.php) прочитает эти переменные и будет отправлять заявки.
